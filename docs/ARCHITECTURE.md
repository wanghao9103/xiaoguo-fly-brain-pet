# 结构与能力边界

## 运行循环

感知简单环境量 → 编码模拟状态 → 选择行动 → 执行动画/移动 → 获得反馈 → 更新行动读出。

输入包括精力、饱食度、互动满足度、好奇程度、鼠标距离/速度、边缘、近期互动、空闲、昼夜和原地陪伴设置。没有截图识别、键盘记录或语言推理。

## 四类状态

- 模型：固定连接、正投影强度、学习权重、计数和 RNG。
- 模拟状态：身体变量、决策时钟、设置、位置和互动事件。
- 短暂交互：手势确认、动画和小游戏，不跨会话重播。
- 显示偏好：角色尺寸，与模型分离。

模型和业务存档严格验证字段、类型、维度及有限数值。损坏主档和备份在替换前保留。

## 反馈归因

单击等待系统双击时限，但保存点击时的行动与特征。其它交互、拖动、暂停或退出会取消旧回调。

小游戏建立 play 上下文，期间暂时停止自主决策覆盖。结果只更新一次；取消、暂停或冻结时不补发奖励。恢复旧存档不会重播游戏。

## 决策证据

last_decision 保存实际决策时的特征、概率和动作，来源区分为：

- network：网络概率抽样，包含探索；
- protection：低精力强制休息；
- interaction：用户发起玩耍。

读取证据不改变 RNG、权重或后续选择。选择记录说明发生了什么，不是因果证明或内心独白。

## 模拟情绪

情绪从原始空闲时间和模拟状态派生。网络的闲置特征在 120 秒饱和，不能代替完整时间；眼泪动画使用持续运行时钟，避免闲置计时封顶后卡住。

情绪展示不改变模型维度、不生成额外奖励，也不证明主观感受。哭是委屈表情，不是学习动作。

## 当前边界

- 桌面仅验证 Windows 主显示器。
- 核心是即时行动价值学习，没有长期规划。
- 奖励与状态规则是工程设计。
- 事件列表用于回看，不是通用记忆推理器。
- 稀疏活动不自动等于更快或更省内存。
- 未做长期数周稳定性、多显示器、语音或自然图片识别验证。
