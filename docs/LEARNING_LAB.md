# 神经网络学习实验室

执行 python lab.py，或双击启动学习实验室.cmd。也可从宠物右键菜单打开。

服务只绑定本机 127.0.0.1。独立启动的实验室在 30 分钟没有请求后退出；从宠物启动的服务随宠物退出停止。

## 手动学习

1. 选择疲劳安静、活力好奇或需要互动。
2. 调整滑块，查看概率与活跃单元。滑块不会训练模型。
3. 选择目标行动，给正反馈或负反馈。
4. 连续奖励 20 次，观察曲线。
5. 试选 100 次，比较概率与有限次随机抽样。

更换情境会重画曲线，权重保留。新建空白脑只重置实验模型。

从宠物菜单打开时可使用“打开时的小果副本”；它是快照，不实时同步。独立启动没有此副本。

## 自动对照实验

| 实验 | 主要问题 |
| --- | --- |
| 情境学习 | 是否学会两个固定情境的不同目标 |
| 奖励反转 | 反馈规则改变后能否调整 |
| 陌生扰动与抗噪 | 原型附近未训练输入的局部稳定性 |
| 新旧习惯干扰 | 新学习是否覆盖旧偏好，复习的代价和收益 |
| 特征敏感性 | 改一个输入对局部概率和活跃单元的影响 |

自动实验从手动模型再克隆，使用内置合成情境，不改手动模型或正式宠物。

## 区分指标

- 行动概率含温度和探索混合，不是成功率保证。
- 随机试选次数会随 RNG 波动。
- 最高概率命中率与随机选择不同。空白模型并列时固定取值，可能产生误导性高分。
- 概率变化用百分点表达，不混作相对变化率。
- 特征敏感性只说明局部变化，不是因果解释。
- 训练干扰来自继续更新权重；当前模型没有独立的时间遗忘机制。

干扰实验的两个训练分支各使用 256 次新增反馈：复习组给新旧情境各 128 次，新学习组全部给新情境。应同时比较新知识习得与旧知识保持。

## 实测示例

空白模型、seed=42、384 单元、每单元 6 输入、Top24：

| 指标 | 结果 |
| --- | ---: |
| 两个训练目标的概率 | 各约 86.7% |
| 反转后的新偏好 | 约 86.7% |
| 反转后的旧偏好 | 约 4.4% |
| ±0.08 扰动的平均目标概率 | 约 84.7% |
| 仅新学习后的旧偏好 | 约 11.0% |
| 等预算复习后的旧偏好 | 约 77.5% |
| 等预算复习后的新偏好 | 约 79.3% |
| 局部最大概率变化 | 约 1.68 个百分点 |

这是合成示例，不能推广成通用智能、真实环境成绩或意识证据。

## 保存与复现

报告保存到 lab_reports，包含：

- experiment_start：不可变起点模型、种子、输入、更新计数和指纹；
- experiment：实验结果；
- current_manual_state：保存报告时的手动状态。

继续训练后，旧结果标记为历史，避免与新模型混装。报告可能含模型偏好，因此默认不纳入 Git。

新建空白脑时，种子决定随机连接；已有模型的自动实验克隆其连接，种子主要控制扰动探针。比较不同初始化，应先更改种子并新建。
