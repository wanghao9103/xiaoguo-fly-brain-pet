# 小果的棋桌：对弈、记忆与学习

## 打开棋桌

双击项目中的 **启动棋桌.cmd**，或运行：

~~~powershell
python lab.py --games
~~~

重新启动小果后，右键菜单也会有 **和小果下棋：五子棋 / 象棋**。从宠物菜单打开时，落子和终局事件会通过队列传回桌宠，显示气泡与短暂表情，并重置互动空闲计时。独立启动棋桌只有网页内的小果，不控制另一个已运行的桌宠。

页面按需打开。独立服务 30 分钟没有请求后退出；重新运行启动脚本即可。宠物内的服务随宠物退出停止。关闭浏览器页签不会立即结束服务；同一记忆目录只允许一张服务棋桌，重复服务会提示目录已占用。同一服务的多个页签共享一局，旧页签的过期操作会被拒绝并刷新。

## 可以怎样玩

- 五子棋：点击空交叉点；你默认执黑先手。
- 中国象棋：先选自己的棋子，再点绿色目标；你默认执红先手。选择后手后棋盘自动朝向你。
- “下一局怎么下”中的执子与搜索水平在重新开局或切换棋种时应用。
- “悔一回合”撤回你与小果各一步，保留小果先手的开局子；终局不能悔棋。
- “认输”结束当前对局并记录结果。
- 五子棋采用 15 × 15 自由规则，五子或长连获胜，无禁手。
- 象棋支持将军、自将过滤、将帅照面、马腿、象眼、炮架、过河和九宫限制；将死与困毙均判负。
- 象棋相同棋盘与行棋方第三次出现判和；400 步封顶和棋。未实现正式比赛长将、长捉裁决。

这是休闲陪练。轻松水平搜索一层；认真水平搜索两层，象棋再对叶子做最多两层吃子／应将搜索，减少连续吃子造成的截断误判。不同局面的耗时不同。

## 果蝇式网络怎样学习

每种棋有独立的 MoveMemory。它借鉴果蝇蘑菇体的稀疏扩展结构，与桌宠原来的四动作网络共享设计思想，不共享权重。

~~~text
合法候选棋步
    ↓ 棋盘几何 / 子力 / 王安全等 12 项特征
互补编码为 24 维
    ↓ 固定随机连接，每个单元接收 6 维
384 个扩展单元 → Top24 → L2 归一化
    ↓ 可训练的标量读出
棋步记忆评分
~~~

规则引擎先排除非法着；搜索老师给候选相对评分。正常候选使用 **70% 搜索评分 + 30% 记忆评分**，按混合值选棋，平局再比较搜索值。立即获胜／必须挡住的五子棋威胁，以及象棋立即将死等优先候选先过滤，再比较。记忆评分不能产生非法着。

实际选棋使用训练前的权重；落子后才用本次搜索示范更新权重。这避免“先抄当前答案，再把命中答案说成网络独立推理”的误读。特征只来自棋盘，不含老师评分或奖励。

两类学习信号：

1. **示范学习**：搜索候选相对得分归一化为目标，用平均批梯度更新读出权重。固定投影不更新。
2. **终局反馈**：最近最多 16 个小果棋步接受胜 +0.9、负 -0.9、和 0 的回报，越早的棋步按 0.9 衰减。只处理实际结束的棋局一次；重新开局或切换棋种不补发未完成结果。

“看示范并学习 5 轮”不移动棋盘，对当前行棋方候选进行五轮示范训练。显示训练前后同批评分的均方误差与建议着；候选得分完全相同且无强制战术时不训练。训练次数指样本被使用的累计次数，不是独立棋谱数量。

关闭“棋步学习与记忆”后，停止示范和终局训练，也暂停已有神经评分参与选棋，改用纯搜索。已有权重保留。悔棋保留已经发生的示范学习，只移除被悔掉的终局归因轨迹。

## 怎样验证真的学了

可以先下一步，查看“记忆评分：前值 → 后值”；再点示范按钮，查看同批误差与训练次数。下完一局后终局样本计数增加。重启服务后两种棋的权重和计数继续保留。

~~~powershell
python -m unittest test_chess_memory test_board_games -v
~~~

测试分别验证：

- 合成正负目标让预测方向分离、同批误差下降。
- 真实五子棋局面中使用可控反事实目标后，混合选招确实改变。此测试只证明网络的因果影响，不证明新着更好。
- 关闭学习后权重与计数完全不变。
- 非法／过期操作和保存失败会回滚局面与模型。
- 胜负反馈只发一次；未完成对局不发终局奖励。
- 序列化往返精确一致、单写者文件锁、损坏备份恢复。
- 桌宠事件改变表情与记事，不将胜负错误奖励给正在“休息/探索”的日常动作。

误差降低只表示拟合这些示范更好。搜索老师可能错，手工特征会损失棋局信息，在线学习可能遗忘，也可能降低棋力。尚未进行大样本对弈基准或 Elo 评估，不能承诺“越玩越强”。这不是从零发现规则、AlphaZero、自我意识或语言思考。

## 本地保存与隔离

棋步记忆位于：

~~~text
%LOCALAPPDATA%\FlyBrainPet\chess\memory.json
~~~

保存两种棋的固定连接、读出权重、学习计数，以及最近 **合计 30 局**完成的棋谱与结果；不是每种棋各 30 局。当前未完成的棋盘只在服务内存中，刷新页签保留，重启服务重新开局。

使用独立文件锁、同目录原子替换和上一份有效备份。损坏文件保留副本；主文件和备份都无法读取时停止加载，不静默清空记忆。日常行为存档仍在上一层目录，棋桌不读取或覆盖它。实验和自动测试使用临时目录；人工验收使用 qa/chess-session，不把测试权重当作真实养成结果。

需要隔离试验：

~~~powershell
python lab.py --games --game-data-dir qa/my-chess-experiment
~~~

棋桌只监听 127.0.0.1，复用本机页面 token、Host/Origin 校验与请求大小上限；不上传棋谱，不需要模型接口、API 密钥或联网服务。
